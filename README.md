## Snake;

This project is me trying to get back into *C#* without creating a huge project and keeping it **very** simple.

## Ideas:
- Leveling system
    -> Transition with a 'next level food' which grows until it fits the screen, then shrinks again to the new snake head. Each level gets more and more difficult.
- Collectible status effects

#### Future:
- Someday add multiplayer with snakes racing for the food.
    -> e.g. first to x points wins.
